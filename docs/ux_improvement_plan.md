# UX改善計画書

## 現状の問題

1. **セッション作成後のフロー**
   - セッション作成後、参加登録ページ（`/s/[joinToken]`）にリダイレクト
   - 参加登録ページには参加URLが表示されない
   - オーナーが参加登録すると、参加URLが表示されなくなる

2. **参加URLの共有**
   - オーナーが参加URLを共有するタイミングが不明確
   - 参加登録後に参加URLが表示されない

## 理想的なUX設計

### 基本方針

1. **参加URLと参加コードは常に表示可能**
   - オーナーはいつでも参加URLと参加コードを確認・共有できる
   - 参加登録前後に関わらず、常にアクセス可能

2. **画面遷移の明確化**
   - セッション作成 → 参加登録ページ（参加URL表示 + 参加登録フォーム）
   - 参加登録後 → セッションページ（参加者機能 + オーナー機能パネル）

3. **オーナーの役割の明確化**
   - オーナーは参加者としても参加できる
   - オーナー機能は折りたたみ可能なパネルで提供
   - 参加URLは常に表示可能

### 画面遷移フロー

```
1. セッション作成
   ↓
2. 参加登録ページ（/s/[joinToken]）
   - 参加URLと参加コードを常に表示（オーナー向け）
   - 参加登録フォーム
   - オーナーも参加者として登録可能
   ↓
3. 参加登録後
   ↓
4. セッションページ（/session/[joinToken]）
   - 参加者としての機能
   - オーナー機能パネル（折りたたみ可能）
   - 参加URLと参加コードも表示（オーナー向け）
```

### 各画面の要件

#### 参加登録ページ（/s/[joinToken]）

**表示内容：**
1. **参加URL共有セクション**（常に表示、オーナー向け）
   - 参加URL（コピーボタン付き）
   - 参加コード（コピーボタン付き）
   - オーナーかどうかをチェックして表示

2. **参加登録フォーム**
   - 表示名入力
   - 持参ボトル数入力
   - ボトルラベル入力（自動入力あり）

3. **セッション情報**
   - イベント名
   - モード（逐次/一斉）

#### セッションページ（/session/[joinToken]）

**表示内容：**
1. **参加者としての機能**
   - 現在のラウンド情報
   - 回答入力
   - 進捗状況

2. **オーナー機能パネル**（折りたたみ可能）
   - 参加URLと参加コード（常に表示）
   - セッション状態に応じたオーナー機能
   - オーナーページへのリンク（別タブ）

3. **Presenterパネル**（該当する場合）
   - Presenterとしての機能

## 実装方針

### 1. 参加登録ページの改善

- 参加URLと参加コードを常に表示
- オーナーかどうかをチェックして表示
- オーナーも参加者として登録可能

### 2. セッションページの改善

- オーナー機能パネルに参加URLと参加コードを常に表示
- 参加登録ページへのリンクも提供

### 3. オーナーページとの連携

- オーナーページから参加者ページに遷移する際、オーナートークンを保存
- 参加者ページでオーナー機能にアクセス可能

```typescript
   - 参加コード: [join_code]
   - コピーボタン

2. セッション情報
   - イベント名
   - モード

3. 参加登録フォーム
   - 表示名
   - 持参ボトル数
   - ボトルラベル
```

### セッションページ（/session/[joinToken]）

```typescript
// 表示セクション
1. オーナー機能パネル（オーナーの場合、常に表示）
   - 折りたたみ可能
   - 参加URLと参加コード（常に表示）
   - セッション状態に応じた機能

2. 参加者としての機能
   - 現在のラウンド情報
```

## メリット

1. **参加URLの常時アクセス**
   - オーナーはいつでも参加URLを確認・共有できる
   - 参加登録前後に関わらず、常にアクセス可能

2. **1画面での完結**
   - オーナーは参加者ページからすべての機能にアクセス可能
   - 別画面を開く必要がない

3. **明確な画面遷移**
   - 参加登録ページ → セッションページの流れが明確
   - 各画面の役割が明確

4. **柔軟な参加方法**
   - オーナーも参加者として参加可能
   - 参加登録ページから直接参加可能
