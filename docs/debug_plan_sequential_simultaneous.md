# 逐次モード・一斉モードデバッグ計画

## 目的
逐次モードと一斉モードの両方が正しく動作することを確認し、エラーがあれば修正する。

## 確認項目

### 1. 逐次モードの動作確認

#### 1.1 ラウンド終了時のリダイレクト
- [ ] 参加者のセッションページで、`revealed`状態のサンプルがある場合、結果ページにリダイレクトされる
- [ ] プレゼンターページで、`revealed`状態になった場合、結果ページにリダイレクトされる
- [ ] オーナーページで、`revealed`状態のサンプルがある場合、結果ページへのリンクが表示される

#### 1.2 結果ページの表示
- [ ] 順位表が正しく表示される
- [ ] 詳細タブが正しく表示される
- [ ] 参加者別タブが正しく表示される
- [ ] 「次へ」ボタンが表示される

#### 1.3 「次へ」ボタンの動作
- [ ] 「次へ」ボタンをクリックすると、APIが呼ばれる
- [ ] 成功メッセージが表示される
- [ ] 全員がクリックしたら、次のラウンドに進む
- [ ] 次のラウンドがない場合、セッションページにリダイレクトされる

### 2. 一斉モードの動作確認

#### 2.1 ラウンド終了時の動作
- [ ] 一斉モードでラウンド終了時、結果ページにリダイレクトされない
- [ ] プレゼンターページで、`closed`状態になった場合、結果ページにリダイレクトされない
- [ ] セッションページで、`closed`状態のサンプルがある場合、結果ページにリダイレクトされない

#### 2.2 通常の動作
- [ ] セッションページが正しく表示される
- [ ] 回答入力が正しく機能する
- [ ] ラウンド終了後の動作が正常に機能する

## 手動テスト手順

### 逐次モードのテスト

1. セッションを作成（逐次モード）
2. 参加者を2人以上登録
3. Roundを開始
4. 全員が回答を提出
5. PresenterがTruthを入力
6. Presenterが採点を完了
7. Roundを終了
8. **確認**: プレゼンターページで結果ページにリダイレクトされる
9. **確認**: 参加者のセッションページで結果ページにリダイレクトされる
10. **確認**: オーナーページで結果ページへのリンクが表示される
11. **確認**: 結果ページが正しく表示される
12. **確認**: 「次へ」ボタンをクリック
13. **確認**: 全員がクリックしたら次のラウンドに進む

### 一斉モードのテスト

1. セッションを作成（一斉モード）
2. 参加者を1人以上登録
3. Roundを開始
4. 全員が回答を提出
5. PresenterがTruthを入力
6. Presenterが採点を完了
7. Roundを終了
8. **確認**: プレゼンターページで結果ページにリダイレクトされない
9. **確認**: セッションページで結果ページにリダイレクトされない
10. **確認**: 通常の動作が正しく機能する

## 既知の問題

### テストの失敗
- 参加登録を締め切るボタンが見つからないエラーが発生している
- 原因: 模擬参加者を作成した後に、UIが更新されるまで待つ必要がある
- 対策: `waitForParticipantsToAppear`を使用するように修正済み

## 修正済みの項目

1. ✅ プレゼンターページで`revealed`状態になった場合、逐次モードであれば結果ページにリダイレクトする処理を追加
2. ✅ オーナーページで`running`状態の時、逐次モードで`revealed`状態のサンプルがある場合に結果ページへのリンクを表示
3. ✅ 参加者のセッションページで`revealed`状態のサンプルがある場合、結果ページにリダイレクトする処理（既に実装済み）

## 次のステップ

1. 手動テストを実行して、実際の動作を確認
2. エラーがあれば修正
3. E2Eテストを修正して、より確実に動作するようにする
