# 最近実装した機能のデバッグ計画

**作成日**: 2025-01-15  
**対象機能**: プレゼンター名表示、参加URLコピー、参加コード機能、逐次モード途中結果ページ修正

---

## 1. 実装した機能の概要

### 1.1 プレゼンター名の表示
- **実装箇所**: 
  - `app/api/round-result/get/route.ts`: ラウンド結果API
  - `app/api/results/get/route.ts`: 最終結果API
  - `app/session/[joinToken]/round-result/[sampleId]/page.tsx`: ラウンド結果ページ
  - `app/session/[joinToken]/results/page.tsx`: 最終結果ページ
- **期待動作**: サンプルの持ち込みプレゼンター名が表示される

### 1.2 参加URLのコピーボタン
- **実装箇所**: `app/o/[ownerToken]/page.tsx`
- **期待動作**: 参加登録URLをクリップボードにコピーできる

### 1.3 参加コード機能
- **実装箇所**:
  - `lib/api-utils.ts`: 参加コード生成関数
  - `app/api/session/create/route.ts`: セッション作成時に参加コード生成
  - `supabase/migrations/add_join_code.sql`: データベースマイグレーション
  - `app/api/session/get-by-code/route.ts`: 参加コードからjoin_token取得API
  - `app/join/page.tsx`: 参加コード入力ページ
  - `app/api/session/get/route.ts`: セッション取得APIでjoin_codeも返す
  - `app/o/[ownerToken]/page.tsx`: オーナーページに参加コード表示
- **期待動作**: 
  - セッション作成時に参加コードが自動生成される
  - オーナーページで参加コードが表示される
  - 参加コードをコピーできる
  - `/join`ページでコード入力して参加できる

### 1.4 逐次モード途中結果ページの修正
- **実装箇所**: `app/session/[joinToken]/round-result/[sampleId]/page.tsx`
- **修正内容**:
  - タブボタンに`type="button"`を追加（画面遷移防止）
  - 「次へ」ボタンの表示条件を改善
- **期待動作**:
  - タブをクリックしても画面遷移しない
  - 「次へ」ボタンが正しく表示される

## 2. デバッグテスト項目

### 2.1 プレゼンター名の表示

#### テスト1: ラウンド結果ページでのプレゼンター名表示
- **手順**:
  1. 逐次モードでセッションを作成
  2. 参加者を登録
  3. ラウンドを開始して回答を提出
  4. ラウンドを終了
  5. 結果ページにアクセス
- **確認項目**:
  - サンプル情報に「持ち込み: [プレゼンター名]」が表示される
  - プレゼンター名が正しく表示される

#### テスト2: 最終結果ページでのプレゼンター名表示
- **手順**:
  1. セッションを完了
  2. 最終結果ページにアクセス
- **確認項目**:
  - 各サンプルに「持ち込み: [プレゼンター名]」が表示される
  - 参加者別タブでもプレゼンター名が表示される

### 2.2 参加URLのコピーボタン

#### テスト3: URLコピーボタンの動作
- **手順**:
  1. セッションを作成
  2. オーナーページで参加登録URLを確認
  3. コピーボタンをクリック
- **確認項目**:
  - コピーボタンが表示される
  - クリックするとURLがクリップボードにコピーされる
  - トーストメッセージが表示される

### 2.3 参加コード機能

#### テスト4: セッション作成時の参加コード生成
- **手順**:
  1. 新しいセッションを作成
  2. オーナーページを確認
- **確認項目**:
  - 参加コードが表示される
  - 参加コードが5文字の英数字である
  - 参加コードがコピーできる

#### テスト5: 参加コードでの参加
- **手順**:
  1. セッションを作成して参加コードを取得
  2. `/join`ページにアクセス
  3. 参加コードを入力
  4. 参加登録を実行
- **確認項目**:
  - 参加コード入力ページが表示される
  - 正しいコードを入力すると参加登録ページにリダイレクトされる
  - 間違ったコードを入力するとエラーメッセージが表示される

#### テスト6: 参加コードの重複チェック
- **手順**:
  1. 複数のセッションを作成
- **確認項目**:
  - 各セッションの参加コードが異なる
  - 重複がない

### 2.4 逐次モード途中結果ページの修正

#### テスト7: タブの画面遷移問題
- **手順**:
  1. 逐次モードでラウンドを終了
  2. 結果ページにアクセス
  3. 各タブ（順位表、詳細、参加者別）をクリック
- **確認項目**:
  - タブをクリックしても画面遷移しない
  - タブの内容が正しく切り替わる

#### テスト8: 「次へ」ボタンの表示
- **手順**:
  1. 逐次モードでラウンドを終了
  2. 結果ページにアクセス
- **確認項目**:
  - 「次へ」ボタンが表示される
  - 参加登録済みの場合は有効
  - 未登録の場合は無効（「参加登録が必要です」と表示）

#### テスト9: 「次へ」ボタンの動作
- **手順**:
  1. 逐次モードでラウンドを終了
  2. 結果ページで「次へ」をクリック
  3. 全員が「次へ」をクリック
- **確認項目**:
  - 「次へ」をクリックするとAPIが呼ばれる
  - 全員がクリックすると次のラウンドに進む
  - 最後のラウンドの場合はセッションページに戻る
