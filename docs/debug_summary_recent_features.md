#### エラー詳細
```
Error: 参加登録を締め切るボタンが見つかりません。参加者が登録されているか確認してください。 (参加者テキスト: false, ボタンテキスト: false)
```

#### 原因分析
- `waitForParticipantsToAppear`は成功している（APIで参加者が確認できている）
- しかし、UIに参加者が表示されていない
- オーナーページのリロードが必要

#### 修正案
1. `closeRegistration`の前にオーナーページをリロード
2. 参加者が表示されるまで待機時間を増やす
3. 参加者リストの表示を明示的に待つ
