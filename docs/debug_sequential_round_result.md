# 逐次モードラウンド結果表示機能のデバッグ計画

## 実装された機能

1. **ラウンド結果取得API** (`/api/round-result/get`)
   - 現段階での順位表（完了したラウンドのみ）
   - 当該ラウンドのサンプル詳細情報
   - 当該ラウンドの参加者別回答

2. **ラウンド結果表示ページ** (`/session/[joinToken]/round-result/[sampleId]`)
   - 順位表、詳細、参加者別の3つのタブ
   - 結果ページと同様の形式で表示

3. **「次へ」ボタン機能** (`/api/round-result/click-next`)
   - 各参加者が「次へ」をクリックしたことを記録
   - 全員がクリックしたら次のラウンドに進む

4. **データベーススキーマ**
   - `round_next_clicks`テーブル（「次へ」ボタンのクリック状態を管理）

5. **自動リダイレクト**
   - セッションページで`revealed`状態のサンプルを検出した場合、結果ページにリダイレクト
