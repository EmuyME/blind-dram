# 逐次モードラウンド結果表示機能のテストチェックリスト

## 前提条件
- ✅ データベーススキーマに`round_next_clicks`テーブルが追加されている
- ✅ 開発サーバーが起動している

## テスト項目

### 1. データベーススキーマの確認
- [ ] Supabaseで`round_next_clicks`テーブルが存在することを確認
- [ ] インデックスが正しく作成されていることを確認

### 2. APIエンドポイントの動作確認

#### `/api/round-result/get`
- [ ] `join_token`と`sample_id`が必須であることを確認
- [ ] 逐次モードでない場合はエラーを返すことを確認
- [ ] `revealed`状態でない場合はエラーを返すことを確認
- [ ] 順位表が正しく計算されることを確認
- [ ] 当該ラウンドの詳細情報が正しく取得されることを確認
- [ ] 「次へ」ボタンの状態が正しく取得されることを確認

#### `/api/round-result/click-next`
- [ ] `participant_token`と`sample_id`が必須であることを確認
- [ ] `revealed`状態でない場合はエラーを返すことを確認
- [ ] 既にクリック済みの場合は成功を返すことを確認
- [ ] クリックが正しく記録されることを確認
- [ ] 全員がクリックしたかどうかを正しく判定することを確認
- [ ] 全員がクリックした場合、次のサンプルが開始されることを確認

### 3. ラウンド結果表示ページの動作確認

#### 基本表示
- [ ] ページが正しく表示されることを確認
- [ ] 順位表タブが表示されることを確認
- [ ] 詳細タブが表示されることを確認
- [ ] 参加者別タブが表示されることを確認

#### 順位表タブ
- [ ] 現段階での順位表が正しく表示されることを確認
- [ ] 各参加者の合計点数が正しく表示されることを確認
- [ ] 各サンプルの点数が正しく表示されることを確認

#### 詳細タブ
- [ ] 当該ラウンドの正解情報が正しく表示されることを確認
- [ ] 参加者の回答が正しく表示されることを確認
- [ ] 正誤マークが正しく表示されることを確認
- [ ] フレーバーレーダーチャートが正しく表示されることを確認
- [ ] その他一覧が正しく表示されることを確認

#### 参加者別タブ
- [ ] 参加者を選択できることを確認
- [ ] 選択した参加者の回答が正しく表示されることを確認
- [ ] フレーバーコメントが正しく表示されることを確認

#### 「次へ」ボタン
- [ ] ボタンが表示されることを確認
- [ ] クリックするとAPIが呼ばれることを確認
- [ ] 成功メッセージが表示されることを確認
- [ ] 全員がクリックしたらメッセージが変わることを確認
- [ ] 次のラウンドがある場合、リダイレクトされることを確認
- [ ] 次のラウンドがない場合、セッションページにリダイレクトされることを確認

### 4. 自動リダイレクトの動作確認
- [ ] 逐次モードで`revealed`状態のサンプルがある場合、結果ページにリダイレクトされることを確認
- [ ] 一斉モードではリダイレクトされないことを確認

### 5. 他の機能への影響確認

#### 一斉モード
- [ ] 一斉モードでラウンド終了時、結果ページにリダイレクトされないことを確認
- [ ] 一斉モードの通常の動作が正しく機能することを確認

#### 通常の結果ページ
- [ ] `published`状態の時に結果ページが正しく表示されることを確認
- [ ] 順位表が正しく表示されることを確認
- [ ] 詳細情報が正しく表示されることを確認

### 6. エッジケースの確認
- [ ] 参加者が1人だけの場合、「次へ」ボタンが機能することを確認
- [ ] 参加者が0人の場合、エラーが発生しないことを確認
- [ ] 次のラウンドがない場合、適切に処理されることを確認
- [ ] `participant_token`が設定されていない場合、「次へ」ボタンが無効化されることを確認

## 確認方法

### 手動テスト手順

1. セッションを作成（逐次モード）
2. 参加者を2人以上登録
3. Roundを開始
4. 全員が回答を提出
5. PresenterがTruthを入力
6. Presenterが採点を完了
7. Roundを終了
8. 結果ページに自動リダイレクトされることを確認
9. 順位表、詳細、参加者別タブが正しく表示されることを確認
10. 「次へ」ボタンをクリック
11. 全員がクリックしたら次のラウンドに進むことを確認

### API直接テスト

```bash
# round-result/get APIテスト
curl "http://localhost:3000/api/round-result/get?join_token=XXX&sample_id=YYY"

# round-result/click-next APIテスト
curl -X POST "http://localhost:3000/api/round-result/click-next" \
  -H "Content-Type: application/json" \
  -d '{"participant_token": "XXX", "sample_id": "YYY"}'
```
